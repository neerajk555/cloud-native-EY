# Lab 9.4: Dashboards (Instructor-Led Grafana Demo + Your Free CloudWatch Dashboard)

**Cost:** ✅ Free for participants (CloudWatch Dashboard); instructor demo uses Amazon Managed Grafana
**Time:** ~15 min

## Objective

Build your own free CloudWatch Dashboard while the instructor demonstrates the same data in Amazon Managed Grafana.

## Prerequisites

- Labs 9.1-9.3 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Watch the instructor's Grafana demo

```bash
# No action — instructor-led, uses the elasticache/grafana instructor-only grant
```


### Step 2: Build your own free dashboard

```bash
aws cloudwatch put-dashboard --dashboard-name dash-$PARTICIPANT --dashboard-body file://dashboard.json
```


## Expected Result

Your CloudWatch Dashboard shows the same Lambda error/latency widgets the instructor showed in Grafana.

## Cleanup

```bash
aws cloudwatch delete-dashboards --dashboard-names dash-$PARTICIPANT
```

## Troubleshooting

- **Why can't I create my own Grafana workspace?**: Amazon Managed Grafana's cost scales per workspace, not per hour of use — 25 workspaces would multiply cost for no added learning value, so it's instructor-demo-only. See SYNC-NOTES.md Amendment 3.
