# Lab 9.1: Viewing Container Insights

**Cost:** ✅ Free Tier (CloudWatch Logs ingestion minimal)
**Time:** ~15 min

## Objective

View the cluster-wide Container Insights data the instructor enabled — you don't install or remove this add-on yourself.

## Prerequisites

- Module 4 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: View your namespace's metrics in the console

```bash
# CloudWatch console -> Container Insights -> Performance monitoring -> filter to ns-$PARTICIPANT
```


### Step 2: Query logs via CLI

```bash
aws logs filter-log-events --log-group-name /aws/containerinsights/course-shared-cluster/application --filter-pattern "ns-$PARTICIPANT"
```


## Expected Result

You can see CPU/memory metrics and logs scoped to your own namespace.

## Cleanup

```bash
Nothing to clean up — you didn't install anything.
```

## Troubleshooting

- **No data for your namespace**: Container Insights takes a few minutes to start reporting after pods are created.
