# Lab 9.3: Distributed Tracing with X-Ray

**Cost:** ✅ Free Tier (100k traces/month)
**Time:** ~15 min

## Objective

Trace a request across two Lambda functions using the shared X-Ray execution role.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
xrayRoleArn=$(aws iam get-role --role-name course-lambda-xray-execution --query "Role.Arn" --output text)
```


### Step 2: Redeploy with tracing enabled

```bash
aws lambda update-function-configuration --function-name hello-$PARTICIPANT --role $xrayRoleArn --tracing-config Mode=Active
```


### Step 3: Invoke and view the trace

```bash
aws lambda invoke --function-name hello-$PARTICIPANT out.json
aws xray get-trace-summaries --start-time $(date -d '-10 minutes' +%s) --end-time $(date +%s)
```


## Expected Result

A trace segment appears for your function's invocation.

## Cleanup

```bash
aws lambda update-function-configuration --function-name hello-$PARTICIPANT --tracing-config Mode=PassThrough
```

## Troubleshooting

- **No traces appear**: Tracing mode must be `Active`, and the function's role must be the X-Ray-permissioned one, not the basic one.
