# Lab 9.2: CloudWatch Alarms on Your Lambda

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Alert on your Lambda function's error rate using the shared basic-execution role's log output.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create an alarm on Errors

```bash
aws cloudwatch put-metric-alarm --alarm-name errors-$PARTICIPANT --metric-name Errors --namespace AWS/Lambda --dimensions Name=FunctionName,Value=hello-$PARTICIPANT --statistic Sum --period 300 --threshold 1 --comparison-operator GreaterThanOrEqualToThreshold --evaluation-periods 1
```


### Step 2: Trigger an error and watch it fire

```bash
aws lambda invoke --function-name hello-$PARTICIPANT --payload '{"forceError":true}' out.json
```


## Expected Result

The alarm transitions to ALARM state within a few minutes.

## Cleanup

```bash
aws cloudwatch delete-alarms --alarm-names errors-$PARTICIPANT
```

## Troubleshooting

- **Alarm never fires**: Confirm the function actually throws on `forceError` — check CloudWatch Logs for the error first.
