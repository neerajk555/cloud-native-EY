# Lab 3.1: Build and Push a Container Image

**Cost:** ✅ Free Tier (ECR storage minimal)
**Time:** ~15 min

## Objective

Build a small Docker image and push it to a personal ECR repository.

## Prerequisites

- Docker installed and running (`sudo systemctl status docker`)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create your ECR repo

```bash
aws ecr create-repository --repository-name demo-$PARTICIPANT --tags Key=Owner,Value=$PARTICIPANT Key=Course,Value=cloudnative-agentic-ai-2026
```


### Step 2: Authenticate Docker to ECR

```bash
acct=$(aws sts get-caller-identity --query Account --output text)
aws ecr get-login-password | docker login --username AWS --password-stdin "$acct.dkr.ecr.us-east-1.amazonaws.com"
```


### Step 3: Build and push

```bash
docker build -t demo-$PARTICIPANT .
docker tag demo-$PARTICIPANT "$acct.dkr.ecr.us-east-1.amazonaws.com/demo-$PARTICIPANT:v1"
docker push "$acct.dkr.ecr.us-east-1.amazonaws.com/demo-$PARTICIPANT:v1"
```


## Expected Result

`aws ecr describe-images --repository-name demo-$PARTICIPANT` shows tag `v1`.

## Cleanup

```bash
aws ecr delete-repository --repository-name demo-$PARTICIPANT --force
```

## Troubleshooting

- **Permission denied on docker.sock**: Add your user to the docker group: `sudo usermod -aG docker $USER`, then log out and back in.
