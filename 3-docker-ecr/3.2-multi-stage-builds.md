**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Reduce image size using a multi-stage Dockerfile.

## Prerequisites

- Lab 3.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

### Step 1: Compare image sizes

```bash

```

The `slim` tag is meaningfully smaller than `v1`.

```bash
docker rmi demo-$PARTICIPANT:slim
```

## Troubleshooting

- **Build stage not found**: Stage names in `FROM ... AS name` are case-sensitive and must match `COPY --from=name`.
