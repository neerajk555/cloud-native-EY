# Lab 2.1: Your First Lambda Function

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Deploy a simple Lambda function using the shared basic-execution role.

## Prerequisites

- Module 1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role ARN

```bash
roleArn=$(aws iam get-role --role-name course-lambda-basic-execution --query "Role.Arn" --output text)
```


### Step 2: Package a trivial handler

```bash
echo 'exports.handler = async () => ({ statusCode: 200, body: "hello" });' > index.js
zip fn.zip index.js
```


### Step 3: Create the function

```bash
aws lambda create-function --function-name hello-$PARTICIPANT --runtime nodejs20.x --handler index.handler --role $roleArn --zip-file fileb://fn.zip --tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 4: Invoke it

```bash
aws lambda invoke --function-name hello-$PARTICIPANT out.json && cat out.json
```


## Expected Result

`out.json` contains `{"statusCode":200,"body":"hello"}`.

## Cleanup

```bash
aws lambda delete-function --function-name hello-$PARTICIPANT
```

## Troubleshooting

- **AccessDenied on PassRole**: You must pass exactly `course-lambda-basic-execution`'s ARN — check for typos. Tag every EC2/RDS/EKS/ALB resource you create with `Owner=$PARTICIPANT` and `Course=cloudnative-agentic-ai-2026` or the create call will be denied by the permission boundary.
