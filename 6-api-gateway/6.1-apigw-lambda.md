# Lab 6.1: API Gateway Fronting a Lambda

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Expose a Lambda function via a REST API using the shared API Gateway execution role.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
apigwRoleArn=$(aws iam get-role --role-name course-apigw-lambda-execution --query "Role.Arn" --output text)
```


### Step 2: Create the HTTP API

```bash
fnArn=$(aws lambda get-function --function-name hello-$PARTICIPANT --query Configuration.FunctionArn --output text)
aws apigatewayv2 create-api --name api-$PARTICIPANT --protocol-type HTTP --target $fnArn
```


### Step 3: Grant API Gateway permission to invoke

```bash
aws lambda add-permission --function-name hello-$PARTICIPANT --statement-id apigw-$PARTICIPANT --action lambda:InvokeFunction --principal apigateway.amazonaws.com
```


## Expected Result

The API's invoke URL returns the Lambda's response.

## Cleanup

```bash
aws apigatewayv2 delete-api --api-id <id-from-create-output>
```

## Troubleshooting

- **403 from the API**: Confirm the `add-permission` call succeeded — API Gateway needs explicit invoke permission separate from your own PassRole grant.
