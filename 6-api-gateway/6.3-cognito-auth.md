# Lab 6.3: Securing the API with Cognito

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Add a Cognito user pool authorizer in front of your API.

## Prerequisites

- Lab 6.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create a user pool

```bash
aws cognito-idp create-user-pool --pool-name pool-$PARTICIPANT
```


### Step 2: Create an app client

```bash
aws cognito-idp create-user-pool-client --user-pool-id <id> --client-name client-$PARTICIPANT
```


### Step 3: Attach a JWT authorizer to your API route

```bash
aws apigatewayv2 create-authorizer --api-id <api-id> --authorizer-type JWT --identity-source '$request.header.Authorization' --jwt-configuration Audience=<client-id>,Issuer=https://cognito-idp.us-east-1.amazonaws.com/<pool-id> --name auth-$PARTICIPANT
```


## Expected Result

Requests without a valid Cognito JWT are rejected with 401.

## Cleanup

```bash
aws cognito-idp delete-user-pool --user-pool-id <id>
```

## Troubleshooting

- **Issuer mismatch**: The Issuer URL must exactly match your pool's region and ID — copy-paste, don't retype.
