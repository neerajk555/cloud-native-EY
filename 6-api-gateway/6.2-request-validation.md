# Lab 6.2: Request Validation and Throttling

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Add a request validator and a usage plan with throttling to your API.

## Prerequisites

- Lab 6.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Add a request validator

```bash
# Console or CLI: apigatewayv2 route request parameter validation
```


### Step 2: Create a usage plan with a rate limit

```bash
aws apigateway create-usage-plan --name plan-$PARTICIPANT --throttle burstLimit=5,rateLimit=2
```


## Expected Result

Requests above the rate limit receive HTTP 429.

## Cleanup

```bash
aws apigateway delete-usage-plan --usage-plan-id <id>
```

## Troubleshooting

- **Usage plan not enforced**: A usage plan must be associated with an API key, not just created standalone.
