# Lab 7.1: App Mesh Basics

**Cost:** ✅ Free (App Mesh control plane has no charge)
**Time:** ~15 min

## Objective

Create an App Mesh mesh and a virtual service, independent of EKS.

## Prerequisites

- Module 3 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create the mesh

```bash
aws appmesh create-mesh --mesh-name mesh-$PARTICIPANT --tags key=Owner,value=$PARTICIPANT key=Course,value=cloudnative-agentic-ai-2026
```


### Step 2: Create a virtual node and virtual service

```bash
aws appmesh create-virtual-node --mesh-name mesh-$PARTICIPANT --virtual-node-name vn-$PARTICIPANT --spec file://vn-spec.json
aws appmesh create-virtual-service --mesh-name mesh-$PARTICIPANT --virtual-service-name vs-$PARTICIPANT --spec file://vs-spec.json
```


## Expected Result

`aws appmesh describe-mesh --mesh-name mesh-$PARTICIPANT` returns ACTIVE.

## Cleanup

```bash
aws appmesh delete-virtual-service --mesh-name mesh-$PARTICIPANT --virtual-service-name vs-$PARTICIPANT
aws appmesh delete-virtual-node --mesh-name mesh-$PARTICIPANT --virtual-node-name vn-$PARTICIPANT
aws appmesh delete-mesh --mesh-name mesh-$PARTICIPANT
```

## Troubleshooting

- **Mesh name collision**: Every mesh is suffixed `-$PARTICIPANT` specifically so 25 people can create meshes without colliding.
