# Lab 7.2: Weighted Traffic Splitting

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Split traffic between two virtual node versions using route weights.

## Prerequisites

- Lab 7.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create a second virtual node (v2)

```bash
aws appmesh create-virtual-node --mesh-name mesh-$PARTICIPANT --virtual-node-name vn-$PARTICIPANT-v2 --spec file://vn-v2-spec.json
```


### Step 2: Create a route splitting 80/20

```bash
aws appmesh create-route --mesh-name mesh-$PARTICIPANT --virtual-router-name vr-$PARTICIPANT --route-name route-$PARTICIPANT --spec file://route-spec.json
```


## Expected Result

Roughly 80% of test requests land on v1, 20% on v2.

## Cleanup

```bash
aws appmesh delete-route --mesh-name mesh-$PARTICIPANT --virtual-router-name vr-$PARTICIPANT --route-name route-$PARTICIPANT
aws appmesh delete-virtual-node --mesh-name mesh-$PARTICIPANT --virtual-node-name vn-$PARTICIPANT-v2
```

## Troubleshooting

- **All traffic to one node**: Check the `weightedTargets` weights in route-spec.json sum correctly and reference the right virtual node names.
