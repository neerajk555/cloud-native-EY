# Lab 0.2: AWS CLI Basics

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Confirm the AWS CLI is installed, configured, and returning your identity.

## Prerequisites

- AWS CLI v2 installed
- Credentials configured via `aws configure`
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Check version

```bash
aws --version
```


### Step 2: Confirm identity

```bash
aws sts get-caller-identity
```


### Step 3: List a free, read-only resource

```bash
aws ec2 describe-regions --output table
```


## Expected Result

`get-caller-identity` returns your IAM user ARN, and `describe-regions` lists AWS regions.

## Cleanup

```bash
Nothing created — nothing to clean up.
```

## Troubleshooting

- **`Unable to locate credentials`**: Re-run `aws configure` with the keys your instructor issued.
