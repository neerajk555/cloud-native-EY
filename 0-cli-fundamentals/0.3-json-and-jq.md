# Lab 0.3: Reading JSON Output with jq

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Practice parsing AWS CLI's JSON output, which every later lab relies on.

## Prerequisites

- jq installed (`sudo apt install jq`)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Get raw JSON

```bash
aws sts get-caller-identity
```


### Step 2: Pipe through jq

```bash
aws sts get-caller-identity | jq -r '.Arn'
```


### Step 3: Use --query as an alternative

```bash
aws sts get-caller-identity --query Arn --output text
```


## Expected Result

Both `jq` and `--query` extract just the ARN string.

## Cleanup

```bash
Nothing created.
```

## Troubleshooting

- **jq: command not found**: `sudo apt update && sudo apt install -y jq`.
