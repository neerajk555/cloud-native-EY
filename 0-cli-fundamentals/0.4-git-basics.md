# Lab 0.4: Git Basics for Lab Code

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Clone and manage the small code snippets used in later labs.

## Prerequisites

- git installed (`sudo apt install git`)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Configure identity

```bash
git config --global user.name "$PARTICIPANT"
git config --global user.email "$PARTICIPANT@example.com"
```


### Step 2: Init a scratch repo

```bash
mkdir -p lab-scratch && cd lab-scratch && git init
```


### Step 3: Commit a file

```bash
echo "scratch" > notes.txt
git add . && git commit -m "first commit"
```


## Expected Result

`git log` shows one commit.

## Cleanup

```bash
cd .. && rm -rf lab-scratch
```

## Troubleshooting

- **git: command not found**: `sudo apt update && sudo apt install -y git`.
