# Lab 0.1: Bash & File System Basics

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Get comfortable navigating and scripting in bash before touching AWS.

## Prerequisites

- Ubuntu 22.04+ (or WSL2 Ubuntu)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Navigate and list

```bash
cd ~
ls -la
```


### Step 2: Create and inspect a file

```bash
echo "hello" > demo.txt
cat demo.txt
```


### Step 3: Variables and simple scripting

```bash
name="training"
echo "Hello, $name"
```


## Expected Result

You can create, read, and script basic file operations in bash.

## Cleanup

```bash
rm demo.txt
```

## Troubleshooting

- **Permission denied**: Check file ownership with `ls -l` and use `chmod`/`sudo` only when you understand why.
