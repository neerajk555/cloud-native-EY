# Lab 8.1: CodeBuild Project

**Cost:** ✅ Free Tier (100 build min/month)
**Time:** ~15 min

## Objective

Build your Module 3 container image automatically with CodeBuild, using the shared CodeBuild execution role.

## Prerequisites

- Module 3 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
cbRoleArn=$(aws iam get-role --role-name course-codebuild-execution --query "Role.Arn" --output text)
```


### Step 2: Create the project

```bash
aws codebuild create-project --name build-$PARTICIPANT --source type=NO_SOURCE --artifacts type=NO_ARTIFACTS --environment type=LINUX_CONTAINER,image=aws/codebuild/standard:7.0,computeType=BUILD_GENERAL1_SMALL --service-role $cbRoleArn --tags key=Owner,value=$PARTICIPANT key=Course,value=cloudnative-agentic-ai-2026
```


### Step 3: Start a build

```bash
aws codebuild start-build --project-name build-$PARTICIPANT
```


## Expected Result

The build succeeds and pushes to your ECR repo from Module 3.

## Cleanup

```bash
aws codebuild delete-project --name build-$PARTICIPANT
```

## Troubleshooting

- **AccessDenied on PassRole**: This role (`course-codebuild-execution`) is one of the two added beyond the original 7 — see SYNC-NOTES.md if it's missing.
