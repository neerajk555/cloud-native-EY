# Lab 8.2: CodePipeline Wiring It Together

**Cost:** ✅ Free Tier (first pipeline free)
**Time:** ~15 min

## Objective

Chain a source stage into your Lab 8.1 build using the shared CodePipeline execution role.

## Prerequisites

- Lab 8.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
cpRoleArn=$(aws iam get-role --role-name course-codepipeline-execution --query "Role.Arn" --output text)
```


### Step 2: Create the pipeline

```bash
aws codepipeline create-pipeline --pipeline file://pipeline-$PARTICIPANT.json
```
pipeline-$PARTICIPANT.json references $cpRoleArn as roleArn and build-$PARTICIPANT as the build action.

## Expected Result

A manual pipeline execution completes both stages successfully.

## Cleanup

```bash
aws codepipeline delete-pipeline --name pipeline-$PARTICIPANT
```

## Troubleshooting

- **Pipeline stuck in Source**: S3-backed source actions need a versioned bucket — confirm versioning is enabled if using S3 as source.
