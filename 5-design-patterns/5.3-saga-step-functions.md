# Lab 5.3: Saga Pattern with Step Functions

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Orchestrate a multi-step transaction with compensating actions, using the shared Step Functions execution role.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
sfRoleArn=$(aws iam get-role --role-name course-stepfunctions-execution --query "Role.Arn" --output text)
```


### Step 2: Create the state machine

```bash
aws stepfunctions create-state-machine --name saga-$PARTICIPANT --definition file://saga.json --role-arn $sfRoleArn --tags Key=Owner,Value=$PARTICIPANT Key=Course,Value=cloudnative-agentic-ai-2026
```


### Step 3: Start an execution and force a failure branch

```bash
aws stepfunctions start-execution --state-machine-arn arn:aws:states:us-east-1:*:stateMachine:saga-$PARTICIPANT --input '{"forceFailure": true}'
```


## Expected Result

The execution history shows the compensating (rollback) steps running after the forced failure.

## Cleanup

```bash
aws stepfunctions delete-state-machine --state-machine-arn arn:aws:states:us-east-1:*:stateMachine:saga-$PARTICIPANT
```

## Troubleshooting

- **AccessDenied on PassRole**: Confirm you're passing `course-stepfunctions-execution`, not trying to create your own role.
