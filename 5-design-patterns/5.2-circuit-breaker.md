# Lab 5.2: Circuit Breaker Pattern

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Implement a basic circuit breaker in a Lambda function calling a flaky downstream.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Deploy the flaky downstream

```bash
aws lambda create-function --function-name flaky-$PARTICIPANT --runtime nodejs20.x --handler index.handler --role $roleArn --zip-file fileb://flaky.zip --tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 2: Deploy the circuit-breaker caller

```bash
aws lambda create-function --function-name breaker-$PARTICIPANT --runtime nodejs20.x --handler index.handler --role $roleArn --zip-file fileb://breaker.zip --tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 3: Invoke repeatedly and observe the breaker open

```bash
for i in $(seq 1 10); do
  aws lambda invoke --function-name breaker-$PARTICIPANT out.json
  cat out.json
done
```


## Expected Result

After several failures, subsequent calls fail fast without invoking the downstream.

## Cleanup

```bash
aws lambda delete-function --function-name flaky-$PARTICIPANT
aws lambda delete-function --function-name breaker-$PARTICIPANT
```

## Troubleshooting

- **Breaker never opens**: Check the failure-count threshold in the sample code matches how many failures you're triggering.
