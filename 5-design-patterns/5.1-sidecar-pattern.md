# Lab 5.1: Sidecar Pattern

**Cost:** ✅ Free (shared cluster)
**Time:** ~15 min

## Objective

Deploy a logging sidecar alongside your main container, namespace-scoped.

## Prerequisites

- Module 4 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Apply a two-container pod spec

```bash
kubectl apply -n ns-$PARTICIPANT -f sidecar-pod.yaml
```


### Step 2: View both containers' logs

```bash
kubectl logs pod/sidecar-demo-$PARTICIPANT -c main -n ns-$PARTICIPANT
kubectl logs pod/sidecar-demo-$PARTICIPANT -c sidecar -n ns-$PARTICIPANT
```


## Expected Result

Two containers in one pod, each independently logging.

## Cleanup

```bash
kubectl delete pod sidecar-demo-$PARTICIPANT -n ns-$PARTICIPANT
```

## Troubleshooting

- **CrashLoopBackOff**: Check your ResourceQuota — a two-container pod uses roughly double the requests of Lab 4.2's single-container pod.
