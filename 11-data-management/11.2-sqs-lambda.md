# Lab 11.2: SQS-Triggered Lambda for Async Writes

**Cost:** ✅ Free Tier
**Time:** ~15 min

## Objective

Process queued writes asynchronously using the shared SQS execution role.

## Prerequisites

- Module 2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
sqsRoleArn=$(aws iam get-role --role-name course-lambda-sqs-execution --query "Role.Arn" --output text)
```


### Step 2: Create the queue

```bash
aws sqs create-queue --queue-name writes-$PARTICIPANT --tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 3: Deploy the consumer with the SQS role

```bash
aws lambda create-function --function-name consumer-$PARTICIPANT --runtime nodejs20.x --handler index.handler --role $sqsRoleArn --zip-file fileb://consumer.zip --tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 4: Wire the queue as an event source

```bash
queueUrl=$(aws sqs get-queue-url --queue-name writes-$PARTICIPANT --query QueueUrl --output text)
queueArn=$(aws sqs get-queue-attributes --queue-url $queueUrl --attribute-names QueueArn --query Attributes.QueueArn --output text)
aws lambda create-event-source-mapping --function-name consumer-$PARTICIPANT --event-source-arn $queueArn
```


## Expected Result

A message sent to the queue is consumed and processed within seconds.

## Cleanup

```bash
aws lambda delete-function --function-name consumer-$PARTICIPANT
queueUrl=$(aws sqs get-queue-url --queue-name writes-$PARTICIPANT --query QueueUrl --output text)
aws sqs delete-queue --queue-url $queueUrl
```

## Troubleshooting

- **Messages not consumed**: Confirm the event-source-mapping's ARN is the queue's ARN, not its URL.
