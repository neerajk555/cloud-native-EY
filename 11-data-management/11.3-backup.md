# Lab 11.3: AWS Backup for DynamoDB

**Cost:** ⚠️ Minimal — partial storage billing may apply even within one cleanup cycle
**Time:** ~15 min

## Objective

Set up an on-demand backup of a DynamoDB table using the shared Backup service role.

## Prerequisites

- A DynamoDB table you created earlier, or create one now
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Fetch the shared role

```bash
backupRoleArn=$(aws iam get-role --role-name course-backup-service-role --query "Role.Arn" --output text)
```


### Step 2: Create a vault

```bash
aws backup create-backup-vault --backup-vault-name vault-$PARTICIPANT --backup-vault-tags Owner=$PARTICIPANT,Course=cloudnative-agentic-ai-2026
```


### Step 3: Start an on-demand backup job

```bash
aws backup start-backup-job --backup-vault-name vault-$PARTICIPANT --resource-arn <your-dynamodb-table-arn> --iam-role-arn $backupRoleArn
```


## Expected Result

`aws backup describe-backup-job` shows the job reaching `COMPLETED`.

## Cleanup

```bash
# List and delete recovery points first, then the vault:
aws backup list-recovery-points-by-backup-vault --backup-vault-name vault-$PARTICIPANT
aws backup delete-backup-vault --backup-vault-name vault-$PARTICIPANT
```

## Troubleshooting

- **Vault won't delete**: It must be empty of recovery points first — delete each recovery point before the vault itself.
- **Charged after cleanup**: AWS doesn't bill storage by the second — a brief backup can still show partial-period cost. This is a known, accepted caveat for this lab.
