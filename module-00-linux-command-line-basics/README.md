# Module 0: Linux Command Line Basics

This module is a **prerequisite warm-up**, not part of the official 15-module course outline — it exists because the course assumes "basic knowledge of the Linux command line," and not every participant starts with that. Complete these labs **before** Module 1 if you're new to the terminal. If you're already comfortable with `cd`, `grep`, `chmod`, and piping commands together, feel free to skip straight to Module 1.
