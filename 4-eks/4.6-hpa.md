# Lab 4.6: Horizontal Pod Autoscaling

**Cost:** ✅ Free (shared cluster)
**Time:** ~15 min

## Objective

Scale your deployment automatically based on CPU, respecting your namespace quota.

## Prerequisites

- Lab 4.2 complete
- Metrics Server installed (Lab 4.0)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create an HPA

```bash
kubectl autoscale deployment web-$PARTICIPANT --cpu-percent=50 --min=1 --max=3 -n ns-$PARTICIPANT
```


### Step 2: Generate load and watch

```bash
kubectl get hpa -n ns-$PARTICIPANT -w
```


## Expected Result

Replica count adjusts within your `max: 3` limit (bounded further by your ResourceQuota).

## Cleanup

```bash
kubectl delete hpa web-$PARTICIPANT -n ns-$PARTICIPANT
```

## Troubleshooting

- **HPA shows <unknown> for targets**: Metrics Server needs a minute or two after install to report metrics.
