# Lab 4.5: ConfigMaps and Secrets

**Cost:** ✅ Free (shared cluster)
**Time:** ~15 min

## Objective

Externalize configuration and sensitive values from your pod spec.

## Prerequisites

- Lab 4.2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create a ConfigMap

```bash
kubectl create configmap app-config-$PARTICIPANT --from-literal=GREETING=hello -n ns-$PARTICIPANT
```


### Step 2: Create a Secret

```bash
kubectl create secret generic app-secret-$PARTICIPANT --from-literal=API_KEY=demo123 -n ns-$PARTICIPANT
```


### Step 3: Mount both as env vars

```bash
kubectl set env deployment/web-$PARTICIPANT --from=configmap/app-config-$PARTICIPANT -n ns-$PARTICIPANT
kubectl set env deployment/web-$PARTICIPANT --from=secret/app-secret-$PARTICIPANT -n ns-$PARTICIPANT
```


## Expected Result

`kubectl exec` into a pod shows `GREETING` and `API_KEY` set as environment variables.

## Cleanup

```bash
kubectl delete configmap app-config-$PARTICIPANT -n ns-$PARTICIPANT
kubectl delete secret app-secret-$PARTICIPANT -n ns-$PARTICIPANT
```

## Troubleshooting

- **Env vars not updating**: Deployments don't auto-restart on ConfigMap change — `kubectl rollout restart deployment/web-$PARTICIPANT -n ns-$PARTICIPANT`.
