# Lab 4.4: Rolling Updates and Rollbacks

**Cost:** ✅ Free (shared cluster)
**Time:** ~15 min

## Objective

Practice zero-downtime updates and rollback inside your namespace.

## Prerequisites

- Lab 4.2 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Update the image

```bash
kubectl set image deployment/web-$PARTICIPANT nginx=nginx:1.28 -n ns-$PARTICIPANT
```


### Step 2: Watch the rollout

```bash
kubectl rollout status deployment/web-$PARTICIPANT -n ns-$PARTICIPANT
```


### Step 3: Roll back

```bash
kubectl rollout undo deployment/web-$PARTICIPANT -n ns-$PARTICIPANT
```


## Expected Result

The rollout completes, then rolling back returns to the prior image version.

## Cleanup

```bash
Already cleaned up by the rollback; delete the deployment when done per Lab 4.2's cleanup.
```

## Troubleshooting

- **Rollout stuck**: Check your ResourceQuota isn't blocking the second replica set from scheduling.
