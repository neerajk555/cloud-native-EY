# Lab 4.0 (Instructor Only): Provision the Shared EKS Cluster

**Cost:** ⚠️ ~$0.10/hr control plane + node costs
**Time:** ~15 min

## Objective

Create the single shared EKS cluster all 25 participants use, with per-participant namespaces, quotas, and RBAC.

## Prerequisites

- Administrator credentials (not a participant user)
- eksctl, kubectl installed
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create the cluster (t3.micro nodes, no NAT)

```bash
eksctl create cluster --name course-shared-cluster --region us-east-1 --nodes 6 --nodes-min 6 --nodes-max 12 --node-type t3.micro --vpc-nat-mode Disable --tags Owner=instructor,Course=cloudnative-agentic-ai-2026
```


### Step 2: Enable the OIDC provider (needed for Module 10.2 IRSA)

```bash
eksctl utils associate-iam-oidc-provider --cluster course-shared-cluster --approve
```


### Step 3: Install Metrics Server cluster-wide

```bash
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml
```


### Step 4: Create a namespace + quota per participant

```bash
while IFS=, read -r username full_name; do
  [ "$username" = "username" ] && continue   # skip CSV header
  ns="ns-$username"
  kubectl create namespace "$ns"
  kubectl label namespace "$ns" owner="$username"
  cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: ResourceQuota
metadata:
  name: quota
  namespace: $ns
spec:
  hard:
    requests.cpu: "1"
    requests.memory: 1Gi
    limits.cpu: "2"
    limits.memory: 2Gi
    pods: "10"
EOF
done < ../../aws-training-setup/scripts/participants.csv
```


### Step 5: Create the shared IRSA role for Module 10.2

```bash
eksctl create iamserviceaccount --cluster course-shared-cluster --name irsa-demo-sa --namespace default --attach-policy-arn arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess --role-name course-irsa-s3-readonly --approve --override-existing-serviceaccounts
```
Trust policy uses a `StringLike` condition on `system:serviceaccount:ns-*:irsa-demo-sa` so it covers every participant namespace.

## Expected Result

`kubectl get ns` shows 25 `ns-<username>` namespaces, each with a `ResourceQuota`.

## Troubleshooting

- **Nodes stuck NotReady**: t3.micro is tight (~1 vCPU/1GB) — give the cluster a few extra minutes on first boot.
