# Lab 4.7: Namespace Cleanup (Students) / Full Teardown (Instructor)

**Cost:** Varies
**Time:** ~15 min

## Objective

Students: clear out your namespace's resources at the end of the module. Instructor: full cluster teardown only at course end.

## Prerequisites

- All prior 4.x labs
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Student: clear your namespace's workloads

```bash
kubectl delete deployment,service,configmap,secret,hpa --all -n ns-$PARTICIPANT
```


### Step 2: Instructor only, course end: delete the whole cluster

```bash
eksctl delete cluster --name course-shared-cluster --region us-east-1
```


## Expected Result

Your namespace is empty (`kubectl get all -n ns-$PARTICIPANT` returns nothing) but still exists for the next module.

## Cleanup

```bash
See steps above — students never delete the cluster or their namespace itself.
```

## Troubleshooting

- **Namespace won't delete (instructor)**: A stuck finalizer usually means a LoadBalancer service wasn't deleted first — remove all Services of type LoadBalancer before deleting the namespace or cluster.
