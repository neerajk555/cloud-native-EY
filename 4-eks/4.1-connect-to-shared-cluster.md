# Lab 4.1: Connect to the Shared Cluster and Verify Your Namespace

**Cost:** ✅ Free (cluster cost is shared, already running)
**Time:** ~15 min

## Objective

Point kubectl at the shared cluster and confirm your namespace and quota exist.

## Prerequisites

- Lab 4.0 completed by instructor
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Update kubeconfig

```bash
aws eks update-kubeconfig --name course-shared-cluster --region us-east-1
```


### Step 2: Set your namespace as default context

```bash
kubectl config set-context --current --namespace=ns-$PARTICIPANT
```


### Step 3: Verify access is scoped

```bash
kubectl get pods
kubectl get pods -n ns-someone-else
```


## Expected Result

You can list resources in `ns-$PARTICIPANT`; the same command against another participant's namespace is denied by RBAC.

## Cleanup

```bash
Nothing to clean up — you don't own the cluster.
```

## Troubleshooting

- **Forbidden on your own namespace**: Confirm you set the namespace to exactly `ns-$PARTICIPANT`, matching your IAM username.
