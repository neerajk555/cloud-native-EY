# Lab 4.2: Deployments and Services in Your Namespace

**Cost:** ✅ Free (shared cluster)
**Time:** ~15 min

## Objective

Deploy a small app and expose it, entirely inside your namespace.

## Prerequisites

- Lab 4.1 complete
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Create a deployment

```bash
kubectl create deployment web-$PARTICIPANT --image=nginx:1.27 -n ns-$PARTICIPANT --replicas=2
```


### Step 2: Expose it

```bash
kubectl expose deployment web-$PARTICIPANT --port=80 --type=ClusterIP -n ns-$PARTICIPANT
```


### Step 3: Verify

```bash
kubectl get pods,svc -n ns-$PARTICIPANT
```


## Expected Result

Two nginx pods running, one ClusterIP service.

## Cleanup

```bash
kubectl delete deployment,service web-$PARTICIPANT -n ns-$PARTICIPANT
```

## Troubleshooting

- **Pods Pending**: You likely hit your namespace's ResourceQuota — reduce replicas.
