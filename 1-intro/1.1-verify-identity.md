# Lab 1.1: Verify Your IAM User & Set $PARTICIPANT

**Cost:** ✅ Free
**Time:** ~15 min

## Objective

Confirm your pre-provisioned IAM user works, understand your permission boundary, and export the `$PARTICIPANT` variable every later lab depends on.

## Prerequisites

- Credentials issued by the instructor
- AWS CLI configured (SETUP-UBUNTU.md)
- `$PARTICIPANT` is exported for this session (see `SETUP-UBUNTU.md`)

## Steps

### Step 1: Confirm identity

```bash
aws sts get-caller-identity
```


### Step 2: Export your participant variable

```bash
export PARTICIPANT=$(aws iam get-user --query "User.UserName" --output text)
echo "You are: $PARTICIPANT"
```
Add this line to `~/.bashrc` (or re-run it each new terminal) so it persists across sessions.

### Step 3: Inspect your permission boundary

```bash
aws iam get-user --query "User.PermissionsBoundary"
```


## Expected Result

You see your own IAM user ARN and a permissions boundary policy attached — not `AdministratorAccess`.

## Cleanup

```bash
Nothing created.
```

## Troubleshooting

- **AccessDenied on get-user**: You may be using the wrong access key pair — double check against the credentials sheet you were issued.
